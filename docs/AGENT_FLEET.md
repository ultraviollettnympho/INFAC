# INFAC Agent Fleet

## Topology
VIOLLETT → HERMES → SPECIALISTS → GSTACK REVIEWS → QA → INFAC REDTEAM → HUMAN REVIEW → GITHUB

Hermes is the command intelligence and canonical integrator. External models are council/divergence engines, not unrestricted editors.

## Specialists
- **architect:** state/data architecture, routes, Substance kernel, failure modes, tests.
- **design:** rooms, interaction grammar, perceptual transformation, typography, motion, sound, responsive/accessibility projection.
- **symbolic:** semantic primitives, glyph registry, state/relationship symbols, candidate/canonical/rejected discipline.
- **content:** artists/projects/places/events/resources, memory fragments, editorial provenance and consent.
- **field:** external research, current-world resources, verification and provenance.
- **redteam:** conceptual adversarial review, gimmick detection, ethics, accessibility, authenticity, dark patterns.
- **qa:** browser, state-transition, accessibility, reduced-motion, audio and regression testing.

## Concurrency
Begin with at most three parallel specialists: architect, design, symbolic. Use isolated worktrees for parallel repository edits. Add content/field after contracts stabilize; use redteam and QA as gates around implementation.

## Council protocol
Give external models the same bounded brief. Normalize their outputs into observations, proposals, risks, implementation implications, and unresolved questions. No model wins by authority.
