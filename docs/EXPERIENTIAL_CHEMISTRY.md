# Experiential Chemistry

A **Substance** is a temporary experiential state, not a visual filter. It changes what a visitor can perceive, hear, traverse, and encounter inside INFAC.

Lifecycle:

OBJECT → INGEST → STATE → TRANSFORMATION → REVELATION → DISCOVERY → COMEDOWN → RESIDUE

A Substance may modify:
- room composition;
- optional sound;
- correspondence visibility;
- artifact access;
- narrative perspective;
- navigation;
- temporal behavior;
- residue.

Each Substance should eventually define: id, name, origin, description, register, activation, duration, visual transformation, audio transformation, available artifacts, revealed correspondences, memory fragments, portal rule/destination, exit behavior, residue, accessibility behavior, and safety notes.

Initial semantic families such as VEIL, NIGREDO, ALBEDO, CITRINITAS, and RUBEDO are provisional vocabulary, not final doctrine.

The same underlying INFAC entities and correspondence graph must power altered states. Do not create a parallel hidden-content universe.

The first hidden-dimension prototype should use a deterministic encounter seed or controlled state transition so QA can reproduce it. Hidden rarity must serve the artwork rather than become a gambling or compulsive-engagement mechanic.

Reduced-motion, mute, keyboard, focus, and immediate-exit paths must preserve semantic access. Provisions never depend on Substance state.
