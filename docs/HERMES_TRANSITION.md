# INFAC → Hermes Transition

Status: active foundation branch

This branch is the reversible integration point for the INFAC agentic workflow. It is based on the imported INFAC foundation rather than the empty initial main.

## Current architecture

INFAC retains:
- rooms as spatial language over normal web routes;
- first-class artists, projects, places, events, resources and publication/residue material;
- correspondence relationships as navigable data;
- evolving symbolic language;
- Provisions as a clear practical channel;
- Residue as unfinished/expired/archaeological material.

## New experiential layer

Substances are now a canonical direction with provisional implementation details.

A Substance is a temporary experiential state, not a CSS filter. It can change:
- room composition;
- optional sound;
- correspondence visibility;
- artifact access;
- narrative perspective;
- navigation;
- temporal state;
- residue.

The first implementation is a vertical slice: one Substance, one altered room, one hidden artifact, one revealed correspondence, one residue event, and an accessible/reduced-motion projection.
