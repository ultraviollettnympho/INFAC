# INFAC Agent Constitution

## Mission
INFAC is an evolving cultural environment presented through an esoteric interface. It is an archive, publication, correspondence system, practical resource channel, and experiential medium.

## Source hierarchy
1. User-authored INFAC decisions.
2. Canon and accepted decision records.
3. Existing INFAC architecture and implementation.
4. External research and model proposals.
5. Agent inference.

Never silently promote inference into canon.

## Rules
- Inspect before changing.
- Preserve provenance.
- Do not invent real-world people, resources, locations, histories, quotes, recordings, or community claims.
- Relationships belong in the data model, not presentation components.
- Every symbol needs registry provenance.
- Every Substance needs an explicit state contract, exit behavior, and accessibility behavior.
- Practical information never requires an altered state.
- Sound is opt-in and never required for comprehension.
- Reduced motion preserves semantic access.
- No generic occult starter-pack identity, fake mythology, spectacle-first WebGL, autoplay sound, surveillance personalization, or compulsive scarcity loops.

## Change protocol
Every meaningful change must state:
1. what experience changes;
2. which canon principle permits it;
3. what remains unchanged;
4. what state/data/routes change;
5. failure modes;
6. tests;
7. reversibility.

## Definition of done
A feature is complete only when semantic model, state transitions, accessibility, tests, browser behavior, red-team review, and provenance/decision records are all accounted for.
