# INFAC ROADMAP

The roadmap is staged around usefulness and actual use rather than feature accumulation.

## Phase 0 — Foundation extraction

**Status: in progress**

- remove host-specific Grok infrastructure
- establish repository identity
- preserve prototype provenance
- establish INFAC operating doctrine
- establish architecture and social boundaries
- make the project independently buildable

## Phase 1 — First public iteration

**Goal: a coherent, functioning INFAC site that can actually be published.**

- stabilize Signal / Work / Theory / Correspondences / Provisions / Residue / Corpus
- replace placeholder branding where the symbolic foundry is ready
- verify every practical resource
- replace fictional/provisional content where it should become real
- establish editorial provenance
- complete mobile and keyboard QA
- deploy

## Phase 2 — Living archive

- add more real projects and artists
- establish publication workflow
- add event records
- improve correspondence graph exploration
- establish contribution conventions
- create an archival provenance format

## Phase 3 — LA field instrument

The Los Angeles transition creates a new practical layer:

- neighborhood orientation
- places and community knowledge
- creative ecology
- survival/income pathways
- housing opportunities
- local resource verification
- event and gathering discovery
- safety/context notes

This should remain useful even when the user does not care about INFAC's aesthetics.

## Phase 4 — Network infrastructure

- artist profiles
- collaboration opportunities
- shared work / earning pathways
- project cells
- affinity groups
- non-market collaboration
- portable contribution records

## Phase 5 — Community contribution

Only after the editorial model is understood:

- submissions
- moderation
- stewardship roles
- verification queues
- contributor identity choices
- change history
- community correction

## Phase 6 — Distributed infrastructure

Longer-term possibilities include portable exports, federated content, cooperative ownership models, shared tools, and infrastructure that does not require a single platform to remain alive.

## What is deliberately not on the roadmap by default

- surveillance analytics
- engagement optimization
- mandatory accounts
- gamification
- speculative token systems
- AI-generated filler content
- giant CMS infrastructure before there is an editorial need
