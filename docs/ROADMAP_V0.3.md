# INFAC V0.3 Roadmap

0. Normalize Git topology while preserving imported foundation history.
1. Build the Substance kernel: registry, activation, session state, duration/exit, state-aware rendering, deterministic encounter seed, residue.
2. Build one complete Substance vertical slice: altered room, optional audio, hidden artifact, correspondence revelation, clean comedown, accessible projection.
3. Add artist-authored Substance content and provenance/consent rules.
4. Make entity projections state-aware so the same artist/work/place can reveal different layers.
5. Prototype the hidden Other Room with one temporary artifact and no commerce.
6. Build correspondence trails rather than graph spectacle.
7. Develop the actual symbolic language alongside implementation.
8. Replace demo data progressively with verified INFAC material and sourced resources.
9. Add structured community contribution before building a giant social backend.
10. Public beta requires rooms, entities, correspondences, Provisions, Residue, Corpus, at least one Substance, one hidden-dimension experiment, and accessibility/provenance documentation.
