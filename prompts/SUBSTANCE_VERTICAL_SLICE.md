# Build Brief: First Substance Vertical Slice

Build the smallest complete proof of INFAC's experiential-chemistry layer.

A visitor enters a normal room, discovers one Substance object, activates it, and experiences a temporary state that:
1. changes room composition;
2. optionally activates controlled audio;
3. reveals one artifact normally hidden;
4. reveals one collapsed correspondence;
5. records residue when the state ends;
6. restores the room cleanly;
7. provides the same semantic revelations through a reduced-motion/accessibility projection.

Do not build the full hidden dimension yet. Do not add a database unless required by the existing architecture. Do not use naive Math.random for the core state transition. Do not fabricate artist memories or recordings. Demo content must be clearly marked. Do not autoplay sound. Provisions must remain independent.

Success means the feature feels like a coherent alteration of the INFAC environment, not a modal, CSS filter, or mini-game.
